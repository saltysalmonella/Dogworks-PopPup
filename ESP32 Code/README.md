# PopPup ESP32 Firmware

This directory contains the source code for the ESP32-based hardware components of the PopPup system.

- **PopPup Collar:** Firmware for the wearable UWB tag. See `PopPup Collar/README.md` for more details.
- **PopPup Node:** Firmware for the stationary UWB node with motor control. See `PopPup Node/README.md` for more details.

## Development
Both projects are built using PlatformIO. Ensure you have PlatformIO installed and configured for ESP32 development.
